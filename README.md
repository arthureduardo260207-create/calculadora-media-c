 Calculadora de Média em C

Programa desenvolvido em **linguagem C** para calcular a média de três notas informadas pelo usuário.

 Sobre o projeto

Este projeto foi desenvolvido durante meus estudos de **Análise e Desenvolvimento de Sistemas (ADS)** com o objetivo de praticar conceitos básicos de programação em C.

O programa solicita três notas ao usuário, realiza o cálculo da média aritmética e apresenta o resultado na tela.

 Funcionamento

O programa:

1. Solicita a primeira nota;
2. Solicita a segunda nota;
3. Solicita a terceira nota;
4. Calcula a média das três notas;
5. Exibe o resultado com uma casa decimal.

 Fórmula utilizada

```text
Média = (Nota 1 + Nota 2 + Nota 3) / 3
```

Tecnologias utilizadas

* Linguagem C
* Biblioteca `stdio.h`

 Conceitos praticados

* Variáveis
* Tipo `float`
* Entrada de dados com `scanf`
* Saída de dados com `printf`
* Operações aritméticas
* Cálculo de média
* Formatação de números

 Exemplo de execução

```text
Digite a primeira nota: 8
Digite a segunda nota: 7
Digite a terceira nota: 9

A media e: 8.0
```

 Estrutura do projeto

```text
calculadora-media-c/
└── media.c
```

 Objetivo

Praticar os fundamentos da linguagem C e desenvolver a lógica de programação por meio de um programa simples de cálculo de média.
